# Revisão da pasta `docs`

## Responsabilidade

A pasta contém documentação de produto, não código executável. Atualmente há apenas uma jornada resumida.

- Regras reais de atendimento.
- Dias e horários de trabalho.
- Política de atraso/cancelamento.
- Materiais inclusos.
- Processo de confirmação.
- Dados reais de cada serviço.
- Critérios de aceite para agenda futura.

Sem essas definições, o código precisa inventar informações ou permanecer como protótipo.
