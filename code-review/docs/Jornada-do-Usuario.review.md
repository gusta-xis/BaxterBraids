## Avaliação

A tabela é boa como rascunho, mas superficial para orientar implementação. Não define cenários alternativos, falhas, dúvidas nem pós-atendimento.

## Jornada mínima recomendada

1. Descobrir a marca.
2. Entender tipos de trança.
3. Comparar preço, duração do procedimento e manutenção.
4. Escolher estilo.
5. Informar data/horário preferidos.
6. Enviar solicitação completa pelo WhatsApp.
7. Receber confirmação humana.
8. Receber orientações de preparação.
9. Realizar atendimento.
10. Receber cuidados pós-procedimento.

O passo 7 é a fronteira atual entre o site e a operação manual.
